# Sudan: Strikes on critical infrastructure, markets and aid/commercial convoys

Interactive map and analysis of reported strikes on Sudan's critical infrastructure, markets and aid and commercial convoys, 1 January – 5 November 2026, drawn from an open-source incident log. Tolls and attributions are as reported and alleged; unverified. Locations are approximate, to town level.

Open `index.html` in a browser, or view it through GitHub Pages.
